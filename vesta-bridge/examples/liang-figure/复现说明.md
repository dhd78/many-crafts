# 图 4-1(d) 复现说明

论文：《合金元素影响面心立方铁性能的第一性原理计算》，梁文艳，中南大学硕士学位论文。
目标图：**图 4-1(d)**，PDF 第 34 页（正文 4.2 节）。

## 原图内容

图 4-1 是 FCC Fe48 与 Fe47X1（X = Cr、Mo、Ni、Pb、Bi）的原子模型：
- (a) Fe48 体材料模型；
- (b)(c) Fe48 / Fe47X1 体材料第 7 层的原子排布；
- (d) Fe47X1 的 (1-11)[1-12] 滑移体系表面模型。

本文复现的是 (d)。

## 模型参数（来自第 34 页正文与图注）

- 超胞：x = [11-2]、y = [1-10]、z = [111]；
- 尺寸：√6/2 a × √2 a × 4√3 a（12 层 (111) 面，共 48 个原子）；
- 第 7 层中的一个 Fe 被 X 取代，形成 Fe47X1；
- 表面模型在 z 方向加 15 Å 真空层，仍保持 12 层；
- 晶格常数取 a = 3.60 Å（论文相关页面未给出，属合理近似）。

## 复现步骤

1. 用 LibreOffice Kit 把 PDF 第 34 页渲染成图片，读图确认图注、轴向和层数；
2. 用 Python 枚举落在超胞内的 fcc 原子（48 个，12 层），把第 7 层中心附近的 Fe 换成 X；
3. 以 `srtio3.vesta` 为模板改写 CRYSTAL 段，生成 `fe47x_surface.vesta`；
4. 用插件 `vesta_export_image` 渲染：

```
vesta_export_image input=fe47x_surface.vesta view=[0.15,1,0] zoom=0.8 boundary=[0,1,0,1,0,1] scale=2
```

`view` 取 [0.15,1,0] 而不是严格的 [0,1,0]，是为了复现原图中"每个位点像一对重叠球"的观感；严格正对时两层的原子会完全重合。

5. 需要对比时，用 `examples/compose.py` 把参考图与 `out-d4.png` 拼在一起（论文原图有版权，不随仓库分发）。

## 与原图的对应关系

| 项目 | 原图 | 复现 |
| --- | --- | --- |
| 层数 | 12 层 | 12 层 |
| X 位置 | 第 7 层 | 第 7 层 |
| 真空层 | 15 Å | 15 Å |
| 观察方向 | 沿 [1-10]，[111] 朝上 | `view=[0.15,1,0]` 近似 |
| 原子观感 | 位点呈重叠双球 | 轻微斜视后一致 |

## 已知差异

- 晶格常数 a = 3.60 Å 为假设值（论文相关页面未给出）；
- X 取 Mo 作为示例，换成 Cr / Ni / Pb / Bi 只需改 `generate.py` 里的 `X_SYMBOL`；
- 原图晶胞看起来比复现图宽，属于原图示意画法与真实晶胞比例不同；
- 只复现 (d)，未复现 (a)(b)(c) 与图 4-2 的距离标注。

## 文件

- `fe47x_surface.vesta` / `fe47x_surface.cif`：VESTA 场景与 CIF；
- `out-d4.png`：最终渲染；
- `out-*.png`：本仓库渲染结果；
