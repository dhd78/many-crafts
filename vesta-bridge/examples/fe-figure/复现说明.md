# 图 3-3 复现说明

论文：《FCC 结构 Fe-Mn-C 合金广义层错能的第一性原理计算》，孙浩，燕山大学硕士学位论文，2021。
目标图：**图 3-3 计算模型**，PDF 第 29 页（正文 3.2.3 节）。

## 原图内容

- (a) FCC-Fe 单胞示意图（含 (111) 密排面 ABC 堆垛）；
- (b) 2×1×4 超胞模型：12 层 ABCABC 堆垛，c 轴上方 15 Å 真空层；
- (c) 超胞俯视图（沿 [111]），标注 b1/b2/b3 与位错反应。

## 复现步骤

1. 用 LibreOffice Kit 把 PDF 第 29 页渲染成图片，读图确认图注与建模参数；
2. 依据正文："以 (111) 密排面为基面，沿 [1-10]、[11-2] 切面，12 层 ABCABC，2×1×4 超胞，c 轴上方 15 Å 真空层"；
3. 用 Python 构建 fcc Fe 超胞（a = 3.60 Å）：
   - a 轴 = 1 × a/2[1-10] = 2.55 Å（视线方向）
   - b 轴 = 2 × a/2[11-2] = 8.82 Å（水平方向）
   - c 轴 = 4 × a[111] = 24.94 Å，再加 15 Å 真空 = 39.94 Å
   - 共 48 个 Fe 原子，12 层；
   - 注：最初把 2× 放在 [1-10]（视线方向），侧视图每层只剩 2–3 个原子，和原图 4–5 个原子的交错排布不符；把 2× 换到 [11-2]（水平方向）后，才出现原图的 4/5 交错（2121）图案。
4. 以 `srtio3.vesta` 为模板，改写 CRYSTAL 段（TITLE / CELLP / STRUC / THERI / SITET / ATOMT / SBOND），生成 `fe_fcc_cell.vesta`、`fe_slab.vesta`、`fe_slab_top.vesta`；
5. 用插件 `vesta_export_image` 的 `view` / `zoom` / `boundary` 覆盖参数渲染：

```
vesta_export_image input=fe_fcc_cell.vesta  view=[1,1,0]  zoom=0.55 scale=2
vesta_export_image input=fe_slab.vesta      view=[1,0,0]  zoom=0.8  boundary=[0,1,0,1,0,1] scale=2
vesta_export_image input=fe_slab_top.vesta  view=[0,0,1]  zoom=4.2  boundary=[0,1,0,1,0,1] scale=2
```

6. 需要对比时，用 `examples/compose.py` 把参考图与三张渲染图拼在一起（论文原图有版权，不随仓库分发）。

## 与原图的对应关系

| 项目 | 原图 | 复现 |
| --- | --- | --- |
| 基面/切面 | (111)、[1-10]、[11-2] | 一致 |
| 层数 | 12 层 ABCABC | 12 层，按层着色 |
| 超胞 | 2×1×4 | 2×1×4 |
| 真空层 | 15 Å | 15 Å |
| 侧视图方向 | 沿 [1-10]，[111] 朝上 | `view=[1,0,0]`，一致 |

## 已知差异

- **晶格常数**：论文相关页面未给出 a，取 a = 3.60 Å（PBE 计算 fcc Fe 通常在 3.45–3.65 Å）。
- **原子半径/配色**：按 A/B/C 层分别着色（青/橙/蓝），与原图观感近似，非论文原始数值。
- **(a) 图**：复现为立方单胞，未包含原图右侧的 (111) 堆垛子图。
- **(c) 图**：是 VESTA 真实投影，没有原图手绘的 b1/b2/b3 箭头、位错反应式与 A/B 标注；复现图的显示范围是窄长矩形，原图是示意性的方形画法。
- 原图 (b) 画了两份（带 15 Å 标注的版本），复现图只画一份。
